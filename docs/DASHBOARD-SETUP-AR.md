# تشغيل لوحة الطلبات والإشعارات

لوحة الطلبات: **https://nayarts.com/admin/**
(للمعاينة بطلبات تجريبية: https://nayarts.com/admin/?demo=1)

كل طلب من الموقع يتحفظ في Google Sheet، وصورة العميل تتحفظ في Google Drive، ويوصل لصاحب البراند إشعار على واتساب وإيميل فيه لينك اللوحة.

## ١. الشيت والكود (مرة واحدة، ١٠ دقائق)
1. ادخل بجيميل البراند على sheets.google.com واعمل شيت جديد باسم **NAY ART Orders**.
2. من القائمة: **Extensions ← Apps Script**.
3. امسح أي كود موجود، والصق محتوى ملف `apps-script/Code.gs` كله.
4. في أول الملف غيّر:
   - `DASHBOARD_PASSWORD`: كلمة مرور قوية للوحة الطلبات.
   - `NOTIFY_EMAIL`: الإيميل اللي توصل عليه الطلبات (لو سبته فاضي هيستخدم نفس الجيميل).
   - `WHATSAPP_PHONE`: رقم واتساب صاحب البراند بكود الدولة (مثال 201270820513).
5. احفظ، واختار الدالة **setup** من فوق، ودوس **Run**، ووافق على الصلاحيات.
6. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - انسخ رابط الـ Web app (بينتهي بـ `/exec`).
7. حط الرابط في إعدادات الموقع: `orders_endpoint` (من لوحة تعديل الموقع ← Settings).

## ٢. إشعار واتساب
اختار طريقة من دول وحط المفتاح في الكود:
- **TextMeBot** (مستقر، حوالي دولار في الشهر): سجّل على textmebot.com، واربط رقم واتساب، وحط المفتاح في `TEXTMEBOT_KEY`.
- **CallMeBot** (مجاني، لكن أحيانًا بيقفل التسجيل): اتبع الخطوات على callmebot.com، وحط المفتاح في `CALLMEBOT_KEY`.

بعدها شغّل الدالة **testNotify** مرة للتجربة. الإيميل بيوصل دايمًا حتى لو واتساب مش متفعّل.

## ٣. تعديل الكود بعدين
أي تعديل في الكود (زي تغيير كلمة المرور): احفظ، وبعدين **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. الرابط بيفضل زي ما هو.

## حالات الطلب
جديد ← تم التأكيد ← بانتظار موافقة التصميم (للوحات من صورة العميل) ← قيد التجهيز ← تم الشحن ← تم التسليم. أو: ملغي (ما بيتحسبش في المبيعات).

## ٤. الدفع الأونلاين (Kashier)
1. افتح حساب تاجر على kashier.io (التجربة مجانية فورًا، والحساب الحقيقي محتاج أوراق النشاط).
2. من لوحة Kashier ← Integrations انسخ: **Merchant ID** و **Secret Key** و **Payment API Key**.
3. في Apps Script ← Project Settings ← Script properties أضف:
   - `KASHIER_MERCHANT_ID`، `KASHIER_SECRET_KEY`، `KASHIER_API_KEY`
   - `KASHIER_MODE` = `test` للتجربة، و `live` بعد التفعيل (ومع live استخدم مفاتيح الـ live).
4. شغّل الدالة **testKashier** مرة؛ لو ظهر في السجل لينك صفحة دفع يبقى الربط سليم.
5. فعّل طريقة الدفع في إعدادات الموقع: `payments.kashier = true` (من لوحة تعديل الموقع ← Settings ← Payment methods).

بعدها: العميل يختار «ادفع أونلاين» ← صفحة Kashier الآمنة ← يرجع لصفحة nayarts.com/pay ← الموقع يتأكد من التوقيع والمبلغ ← الطلب يتعلّم «مدفوع» في اللوحة لوحده ويوصلك إشعار. كل العمليات بتتسجل في شيت «Payments log».

## ٥. ملف الطباعة التلقائي للوحات من صورة العميل (Mimi Panda)
1. اشترك في خطة **Commercial** على mimi-panda.com (مطلوبة للاستخدام التجاري).
2. من **My profile ← API Token** اعمل مفتاح وانسخه.
3. في Apps Script ← Project Settings ← Script properties أضف `MIMI_TOKEN` بالمفتاح. (اختياري: `MIMI_COLORS` عدد الألوان، الافتراضي 24.)
4. شغّل الدالة **testMimi** مرة؛ لو ظهر في السجل `200` يبقى الربط سليم (مش بيستهلك تحويلات).

بعدها: لما تدوس «✓ تم وصول الدفع» على لوحة من صورة العميل، الصورة بتتبعت لـ Mimi Panda لوحدها بمقاس اللوحة واتجاهها. خلال دقيقة لـ 3 دقايق يظهر في الطلب: معاينة بعد التلوين، اللوحة المرقّمة، الألوان، وأزرار تحميل ملف الطباعة (PDF / SVG) وجدول الألوان. ابعت صورة المعاينة للعميل، ولما يوافق دوس «العميل وافق» والطلب يتنقل لـ «قيد التجهيز». كل الملفات بتتحفظ كمان في Google Drive.
